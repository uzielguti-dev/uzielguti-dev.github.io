## What is Hippocampus? **Hippocampus** is a drop-in memory layer for AI agents that remembers everything across conversations. It gives your AI assistant a working memory that persists between sessions, making interactions feel continuous and personal. This tool is built for developers but runs smoothly on any modern Windows PC with minimal setup. --- ## 🎯 Key Features | Feature | What It Does For You | |---------|----------------------| | **4-Channel Retrieval** | Finds the right memory from multiple angles—semantic, temporal, keyword, and entity-based—so nothing gets lost | | **Dual-Track Isolation** | Keeps separate memory tracks for different tasks, preventing confusion between unrelated projects | | **Conflict Confirmation** | When memories disagree, the system asks you to confirm which is correct instead of guessing | | **OpenAI-Compatible Proxy** | Works as a simple replacement for the OpenAI API—just change one URL and you're done | | **LangGraph Agent Integration** | Pre-built agent wrapper for advanced workflows using the LangGraph framework | | **Benchmarked Accuracy** | Tested on official LoCoMo-10 and LongMemEval datasets with verified results | --- ## 💾 What You Need Before Starting - **Operating System:** Windows 10 or 11 (64-bit) - **Disk Space:** At least 500 MB free - **Internet Connection:** Required for the initial download and LLM API access - **A Free Account:** An API key from any LLM provider (like OpenAI, Anthropic, or local options) --- ## 📥 How to Download 1.
